# Paper draft

The 14 October 2026 rewrite uses final-layer results only. The main argument proceeds from predictive Pareto fronts to separate behavioral and neural group regressions, then to representational comparisons and interpretation.

Build from this directory with the site's TeX Live installation:

```bash
source /usr/share/Modules/init/bash
module load texlive/20240312
pdflatex -interaction=nonstopmode -halt-on-error main_iclr2027.tex
bibtex main_iclr2027
pdflatex -interaction=nonstopmode -halt-on-error main_iclr2027.tex
pdflatex -interaction=nonstopmode -halt-on-error main_iclr2027.tex
```

The main regression table reproduces model 3 from `reports/matched_scale_regression_report_{embedding,surprisal}.pdf`, checked against `outputs_jeanzay/matched_scale_report/regression_coefficients_{embedding,surprisal}.csv`. It uses ceiling-normalized outcomes and model-based mixed-model standard errors, with separate fits by response domain. No family-clustered inference is claimed.

The RDM-regression figures intentionally use the versions reviewed in `reports/rsa_summary/figures/`, rather than the different aggregation in `reports/rsa_summary/dll_pareto/`. Do not substitute one without updating the methods and frontier descriptions.

`sections/score_ranges_table.tex` uses the two saved `master_table_*_last.csv` inputs. `sections/rsa_summary_table.tex` uses `reports/rsa_summary/rsa/summary_correlation.csv` and `summary_dll.csv`; these are pooled descriptive correlations, not the category-specific slopes in the older panel figures. The model and dataset inventory tables are retained from the existing draft. Best-layer results, DLT analyses and the old IQR-scaled result macros are not part of this draft. The ceiling tables (`corr_ceiling_table`, `dll_ceiling_table`, `rsa_ceiling_table`, `rdm_dll_ceiling_table`) and the group-median table (`results_medians_table`) are generated by `build_supporting_tables.py` from `outputs/benchmark_summary/`, `outputs/noise_ceilings/` and `reports/rsa_summary/` (run `.venv/bin/python paperwriting/build_supporting_tables.py` from the repository root). `ridge_config_table.tex` and `lme_formulas.tex` are hand-maintained descriptions of the configs; `lme_formulas.tex` was updated on 14 October 2026 for the ROI-wise Pereira fit.

The draft is an evidence-based rewrite, not a new statistical analysis. In particular, it does not add dependence-aware regression fits, cross-modality coefficient tests, frontier uncertainty estimates, or a fresh audit of every dataset's extraction and fitting pipeline. Those limits are stated in the manuscript.
